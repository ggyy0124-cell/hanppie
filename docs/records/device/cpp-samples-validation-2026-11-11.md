## 发布环境复核与修正

初版 HTML 在 Ubuntu g++ 9.4 和 13 上编译「好奇哨兵」「萤火虫花园」「点球守门员」失败，另外 18 份通过。生成器丢失了预置节目原有的匿名命名空间，令辅助函数 `sleep(double)` 与单头文件间接引入的 POSIX `sleep(unsigned int)` 在整数参数处产生歧义；Windows 编译未覆盖这一差异。

生成器恢复预置节目辅助函数和节目函数的匿名命名空间，保留源代码作用域。CI 增加在 Linux 上编译、链接网页实际嵌入的全部代码，只检查构建、不运行机器人。SDK 头文件与校验值不受此修正影响。修正后的 Linux 结果以 PR 新提交检查及发布方复验为准，旧提交的 CI 通过不能替代这项检查。
