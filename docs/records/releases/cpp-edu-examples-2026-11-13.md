# C++ SDK 0.0.12 · 恢复 edu 网页示例

[记录索引](../README.md) · [课堂服务](../../../cpp/classroom/README.md)

0.0.11 更新课堂网页时仅收录已确认的 ctrl 机器人样例，移除了原有 edu 入门演示。0.0.12 恢复「前进、转弯」「走正方形」，保留原有 21 个示例，网页共 23 个示例。

两个 edu 程序的权威源码位于 `cpp/examples/edu/`，网页生成器读取源码并替换单头文件 include；CMake 同时提供独立构建目标。动作返回失败时不继续后续动作，并断开连接、返回非零退出码。程序使用原有 edu API，本次未修改控制库行为。

两个 edu 程序尚未实机验证。网页代码开头明确标注验证状态和场地要求，不能继承 ctrl 样例的实机结论；正方形边长按运动时间估算。

本机已验证 Windows MinGW 构建（含两个新增目标）、0.0.12 TDM-GCC 4.9.2 单头文件检查、生成同步检查、Ruff 与 Pyright 严格检查。Chrome 使用模拟服务验证 23 个示例切换、两个 edu 源码及验证提示、默认输入、成功/编译错误恢复，并检查桌面、平板和手机横屏无水平溢出。模拟服务检查不代表实机或发布服务验收。

真实发布环境的编译、运行/停止及窗口适配由发布方另行检查；本轮未执行机器人动作，也未进行 Android 验证。
